# CanvApps VS Code Extension 🎨

Language support, syntax highlighting, and code snippets for **CanvApps** `.cvs` Single-File Components.

## Features

* 🌈 **Full Syntax Highlighting:** Embedded TypeScript support for `<script lang="ts">`, custom canvas tags (`<view>`, `<text>`, `<button>`, `<input>`), directives (`*if`, `*for`), dynamic bindings (`:prop`), and event handlers (`@event`).
* ⚡ **Code Snippets:** Rapid boilerplate generation with `cvs-component`, `cvs-view`, `cvs-text`, `cvs-button`, `cvs-input`, and `cvs-signal`.
* 🛠️ **Tag Auto-Closing & Bracket Matching:** Seamless editing experience.

## Installation

### Method 1: Local Link
Copy or link the extension folder to your VS Code extensions directory:
```bash
cp -r CanvApps/extension ~/.vscode/extensions/canvapps-vscode
```

### Method 2: VSIX Package
```bash
code --install-extension canvapps-vscode-0.1.0.vsix
```
